# Markora 的 Markdown 格式支持

适用于 Markora 0.85.0，包含 0.84.0 开发阶段引入的能力。表中「正文编辑」指可以在显示出来的文字中放置光标并修改。双击只读预览、在编辑区按 Option+Enter，或选择「⋯ → 当前块源码」可以检查当前块。草稿和可写文件可以修改块源码，在预览中核对后「应用并返回」，然后按需要保存。

| 阶段与格式 | 阅读与操作 | 已知边界 |
| --- | --- | --- |
| MD-01 · CommonMark / GFM | 标题、段落、强调、链接、引用、代码、列表、任务、水平线与表格。非矩形表格的显示以表头列数为准，保留单元格对齐。大纲可定位标题，查找可命中只读预览。 | 只读命中可以定位。包含只读命中的批量替换会整体拒绝。正文中的链接地址不会触发联网。 |
| MD-02 · 行内写作 | 常见转义、实体、删除线、多反引号代码、显式引用式链接标签和 Setext 标题支持有源码边界的正文修改。查找替换也会核对修改后的整篇结构。 | 短引用的标签同时决定目标。会改变引用目标、围栏结构或作用范围的输入可能需要块源码。 |
| MD-02 · 结构写作 | 支持范围内的列表、引用和表格可修改文字。矩形表格内的转义竖线可修改；带元信息的围栏和缩进代码支持能保留结构的多行输入。含扩展格式的顶层段落可在同一普通文本片段内拆段或粘贴多段。 | 表格直接写作上限为 8 列、32 行。跨单元格、复杂嵌套和含糊的跨标记选区保留源码入口。原文件的未改部分、换行和可撤销修改保留。 |
| MD-03 · 数学与图表 | 行内及块级公式生成本地 MathML；Mermaid 由随包引擎渲染为只读图片。局部源码可以边改边看结果。 | 单个公式或图表上限 8,192 个 UTF-16 单元。语法错误会保留源码；图表中的交互、外部资源和嵌入配置受限。 |
| MD-03 · 扩展文档结构 | 脚注引用与定义可以往返；支持同文档的 `[[#标题\|显示文字]]`，以及 NOTE、TIP、IMPORTANT、WARNING、CAUTION 提示块。文首带键值的成对 `---` 元数据块按原文展示。 | Wiki 不打开其他文件。元数据仅展示，不执行 YAML 标签。HTML 以惰性文本呈现，未获授权的图片或外部资源不会自动读取。 |

## 如何解释规范样例结果

仓库固定了 CommonMark 0.31.2 的 652 例和 GFM 0.29 的 677 例。测试逐例校验真实编辑器节点树，并将其显示结构、可见文字和行内标记与规范 HTML 对照。比较会归一化空白、等价标记顺序、编辑器光标段落和列表、单元格的内部段落。表格对齐、链接属性、源码还原和交互由单独用例验证。

两套规范共 1,329 例，其中 1,116 例的归一化结果一致，213 例有登记差异，主要涉及原始 HTML、图片、输入中的快捷前缀、裸链接或 Wiki 扩展。每个差异都对应具体样例编号。规范样例覆盖阅读语义；真实输入法、VoiceOver 和长期人工写作需要独立记录。

## 0.85.0 格式验收范围

下表列出本版各项能力的适用范围与验收标准。

| 格式 | 显示 | 正文操作 | 撤销与重做 | 保存并重开 |
| --- | --- | --- | --- | --- |
| 粗体、斜体、删除线、反引号代码、行内链接 | 最后一个定界符输入后显示对应格式 | 在单行普通段落末尾逐键输入，继续键入标点 | 核对闭合前的源码与闭合后的标记 | 保留输入的定界符与链接拼写 |
| 矩形表格 | 维持现有列数、表头与对齐 | 在单元格中粘贴矩形 TSV，覆盖范围内的普通文本格；越界、非矩形、会改动格式的粘贴应整体拒绝 | 一次撤销整次粘贴，重做恢复全部目标格 | 其他行、格式和换行按原始字节核对 |
| 不规则表格 | 按表头列数补齐或隐藏多余格 | 可查找可见文字，在同一个单元格内区分重复命中 | 只读命中允许定位，混合替换整体拒绝 | 修改表格外正文后，隐藏的多余格仍在磁盘上 |
| 引用中的列表 | 保留引用和列表的嵌套关系 | 在显式引用前缀下拆分普通文本列表项，与前一同级项合并 | 保留其他项、原有换行和引用前缀 | 按来源文件核对完整内容 |
| 元数据与分隔线 | 首条分隔线后空一行进入正文；紧接的键值行可声明元数据，也允许前置注释行 | 元数据由块源码编辑 | 验证源码撤销 | 保留分隔线、注释和换行 |

本轮真实输入法、VoiceOver 和真人长时间连续写作均未测。受控窗口测试、规范样例和人工验收分别记录。
